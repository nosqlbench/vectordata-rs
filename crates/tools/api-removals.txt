# Intended removals of public API paths, read by the release guard
# `cargo run -p tools --bin api-paths` (AC-5 / CB-3 of
# docs/design/srd-crate-boundaries.md).

# Line format:  <baseline-tag> <path>  # reason

# A line applies only when its tag is the baseline being checked, so an
# entry never excuses a later, accidental removal of the same path. Any
# path that stops resolving (unresolved or private) since the baseline
# and is not listed here fails the guard.
